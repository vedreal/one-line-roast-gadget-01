Entry for the [make.fun bounty "One-Line Roast: The Gadget You Use Every Day"](https://make.fun/bounty/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610) — write one original line, up to 200 characters, roasting a gadget or app you use every day.

## The program

`main.py` (Python 3, standard library only, no network) writes exactly one
line to `/output/entry.txt`:

> My smartwatch congratulates me for standing up, as if sitting was the hardest part of my day.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The output is deterministic: the same line, every run.
